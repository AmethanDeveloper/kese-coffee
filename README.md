# Kese Coffee — предзаказ кофе с собой

Сайт-приложение для кофейни на вынос в Астане. Гость заказывает напиток заранее и забирает его без очереди, бариста ведёт заказы в панели персонала.

**Демо:** https://kese-coffee.netlify.app — демо-режим: заказы и аккаунты хранятся только в браузере, панель персонала открывается по кнопке «Войти как владелец».

## Возможности

**Для гостя**
- меню с фото, объёмами и метками «Хит»; заказ с выбором времени готовности;
- push-уведомления о статусе: принят, счёт в Kaspi, готов, отменён;
- установка на телефон как приложение (PWA) — Android и iPhone;
- аккаунт с историей заказов (вход по почте, опционально Google).

**Для персонала** (`/#admin`)
- доска заказов: новый → принят → готов, заказы «у стойки»;
- push-уведомления о новых заказах на телефоны бариста;
- статистика за день: число заказов, выручка, средний чек;
- редактирование меню, цен и настроек заведения.

## Устройство

```
Гость / бариста (PWA, без сборки) ──► Supabase: Auth + PostgreSQL + RLS
                                          │  триггер (pg_net) на новый заказ
                                          ▼
                       push-server (Node.js, web-push, VAPID)
                       systemd-служба kese-push на 127.0.0.1:8787
                                          ▲
                       Caddy: HTTPS, раздача сайта, /push/* → push-server
```

| Папка / файл | Что это |
| --- | --- |
| `index.html`, `js/`, `css/`, `sw.js` | приложение гостя и панель персонала (vanilla JS, service worker) |
| `supabase/schema.sql` | таблицы, правила доступа (RLS), функции и стартовое меню |
| `push-server/server.js` | сервер Web Push для уведомлений |
| `deploy.sh` | установка на Ubuntu одной командой: Caddy, HTTPS, systemd-служба |
| `ИНСТРУКЦИЯ.md` | подробная инструкция по запуску |

## Быстрый старт

Пока в `js/config.js` пустые `SUPABASE_URL` и `SUPABASE_KEY`, приложение работает в **демо-режиме**: данные хранятся только в браузере. Достаточно открыть `index.html` через любой статический сервер:

```bash
python -m http.server 8080
```

Боевой запуск (Supabase + свой сервер) описан в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md):

```bash
DOMAIN=order.example.kz bash deploy.sh
```
